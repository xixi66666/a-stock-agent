# 同花顺 Financial-API 接入

本次接入将同花顺 Financial-API 设为已覆盖能力的第一顺位数据源；旧有腾讯/新浪/东财等适配器仍作为按分区降级的备用来源，不开放任意 URL 或 HTTP 工具。

## 本地配置

在 Git 忽略的 `config/application-local.yml` 中配置 `hithink.enabled: true` 和 `hithink.api-key`；示例文件仅放占位符。未启用或未配置密钥时不发起请求。密钥只经 `X-api-key` 请求头发往官方服务，带凭据的请求禁止自动重定向，供应商错误正文不回显。

## 数据路径与限制

- 最新行情优先同花顺，证券名称通过同花顺元数据补齐；成交量单位为股、成交额单位为元。源接口不提供成交时间、换手率、量比和市值时保留空值并在 issues 中说明。
- 个股日线优先同花顺前复权接口，基准指数日线优先同花顺指数接口；请求窗口有界、校验证券身份、OHLC 关系、重复日期、顺序和专业历史长度。腾讯/百度只在同花顺数据不可用或陈旧时局部接管。
- 财报优先同花顺：利润表、资产负债表、现金流量表各最多 8 期年报，按报告日期对齐，金额单位为人民币元。季度累计口径未确认，因此不使用季度数据；历史缓存 30 分钟。
- 不将股东权益合计当作归母权益。流动负债、股本、归母权益缺失时保留空值，对应质量信号不能评估。
- 同比与上年比较按实际报告日期匹配，不将年报的前四条记录误当作上年。
- 估值优先同花顺，独立返回在研究快照的 `valuation` 中，缓存 5 分钟；页面和报告展示 PE TTM、PE MRQ、PB MRQ、PS TTM、PCF TTM。负值保留，空值不转成零。
- 分红/送股优先同花顺公司行动接口；每股现金分红保持税前元，送股换算为每十股。最新交易日龙虎榜优先同花顺，并写入 `capital.components.dragonTiger`；接口未提供换手率时保持空值。融资融券、大宗交易、股东户数和解禁仍从旧适配器提供，并在 `capital.components.legacyCapital` 标明来源。
- 同花顺公开接口当前未覆盖或本项目尚未建立规范化模型的资金流、融资融券明细、大宗交易明细、股东户数、解禁明细、行业映射、研报、新闻和公告，继续使用各自原适配器；这些分区不会被同花顺空结果伪造替代。
- 估值源时间是供应商聚合时间，不代表各指标同一时刻更新。缺时间或时间超前标记未验证，超过七天标记陈旧。
- 页面、API 与财报/机构报告证据包保留数据来源、源时间、抓取时间、缓存标记、备用来源及数据限制；失败不影响其他研究区块。

## 验证

默认 Maven 测试不访问外部服务。`HithinkFinanceClientTest` 使用本机 HTTP 服务检验协议、精度、空值及错误状态；`HithinkResearchGatewayTest` 检验主备和缓存；`AnnualFinancialAnalysisTest` 检验年报同比。`tests/ui/hithink.spec.js` 使用离线数据验证四种视口及来源展示。

真实接口检查需显式使用 `-Pexternal -Dtest=HithinkLiveDataIT`，读取本地凭据，产物仅写入被忽略的 `target/data-verification/`。不要将本地配置或带私密头的原始响应复制到测试夹具。

接口依据：[Financial-API 官方仓库](https://github.com/HiThink-Tech/Financial-API)。
